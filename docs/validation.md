## 2026-11-18：拓竹云端实机验收（cn 区，用户授权的令牌）

以下是使用授权账号对 X2D 与 A1 mini 完成的有限只读验证结果。

- 任务同步：两款机型的任务均可读取，重复同步按云端 ID 去重。
- 设备关联：云端任务 `deviceId` 可匹配打印机序列号；补录设备后重同步可回填未核对任务。
- 材料明细：一项 X2D 多材料任务的逐材料克重、颜色和总重与 Studio 一致。
- 状态契约：与 Studio 对照确认 `status` 2 为成功、3 为已取消；缺乏验证的数值 4 保留为未知。
- 非成功保护：核对非成功任务时，接口按设计要求显式确认实际消耗（自动化测试中触发验证）。

待办：真实任务的核对→扣减→撤销流程由用户按既有产品流程操作确认；耗材库存云端同步已实现为实验功能（2026-11-18）。

## 2026-11-18：云端耗材库存同步（实验功能，实机验证）

- 端点：`GET /v1/design-user-service/my/filament/v2`（cn 区实测）。样本覆盖手动录入的非 RFID 料卷，返回稳定 ID、品牌、系列、材质、颜色、重量和可选设备关联。`netWeight` 为云端报告值。
- 合并策略（防覆盖）：只新增本地没有的卷；同规格唯一、或多卷中剩余克重 ±1g 唯一命中的卷回链 `cloud_spool_id`；克重差异仅报告、永不覆盖本地人工确认数值。
- 实机结果：成功匹配已有料卷并报告克重差异。无法区分的同规格料卷可保留为人工处理项。
- 迁移 003 为纯增量列（`spool.cloud_spool_id`），功能回退后该列闲置无副作用；代码按适配器/服务/前端三个提交分粒度落库，可单独 revert。
- 自动化：39 项测试（新增库存同步路径、库存条目解析），类型与格式检查通过。
